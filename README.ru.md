# Steam & Epic Deals Bot

[Читать на английском](README.md) | Русский

Telegram-бот для отслеживания скидок в Steam и бесплатных раздач в Epic Games. Steam работает, Epic — в разработке.

Написан на TypeScript, grammY и SQLite.

## Возможности

- **Скидки Steam:** топовые предложения и фильтры (50%+ / 75%+ / 90%+), постраничные карточки.
- **Локализация:** английский и русский, определяется автоматически из Telegram при первом запуске.
- **Мультивалютность:** USD, EUR, RUB, UAH, KZT.
- **Уведомления:** ежедневная рассылка обновлений Steam в 12:00 UTC, отключается в настройках.
- **Кэш:** SQLite хранит скидки, детали и историю изменений — никаких запросов к API при рендере.
- **Логирование:** структурированные JSON-логи через pino.

## Быстрый старт

```bash
npm install
cp .env.example .env
# укажите BOT_TOKEN в .env
npm run dev
```

## Скрипты

- `npm start` — продакшн-сервер
- `npm run dev` — сервер разработки с watch-режимом

## Переменные окружения

| Переменная             | По умолчанию | Описание                                                          |
| :--------------------- | :----------- | :---------------------------------------------------------------- |
| `BOT_TOKEN`            | -            | Токен бота из [@BotFather](https://t.me/BotFather)                |
| `CRON_SCHEDULE`        | `0 12 * * *` | Расписание ежедневного обновления (UTC)                           |
| `LOG_LEVEL`            | `info`       | `debug` / `info` / `warn` / `error`                               |
| `PRIME_CACHE_ON_START` | `true`       | Загружать скидки при старте                                       |

## Архитектура

Код разделён на слои, чтобы API-клиенты, база и UI бота не смешивались:

- **`sources/`** — единственное место, которое ходит во внешние API. Больше нигде нет HTTP-запросов.
- **`db/`** — хранилища SQLite, по файлу на домен (`users.db.ts`, `steam.db.ts`).
- **`tasks/`** — cron-задачи. `updateSteamDeals` тянет свежие данные в SQLite, `broadcastSteamUpdate` рассылает подписчикам.
- **`core/`** — логика бота: хендлеры, экраны, клавиатуры. Читает из `db/`, никогда не ходит в API.
- **`locales/`** — словари `en` / `ru`, выбираются per-user через `AppContext`.
- **`types/`** — общие типы TypeScript, зеркалят структуру `src/`.
